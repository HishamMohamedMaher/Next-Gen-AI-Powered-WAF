## 6. نصائح تقنية محددة (توفّر وقت)

### الـ Normalizer — بسّطوه
```
النسخة الكاملة في التوثيق:
  URL decode iterative + HTML entities + NFKC + Null bytes
  + comments → space + conditional comments extraction
  + Hex candidates + Base64 candidates + JSON field-by-field

النسخة الأولى (يوم 5):
  URL decode iterative + HTML entities + NFKC + Null bytes
  + comments → space + conditional comments extraction
  
الباقي يتضاف لو فيه وقت.
```

### الـ Signatures — ابدأوا بالجاهز
بدل ما تكتبوا كل regex من الصفر، خدوا **أهم 20-30 قاعدة من CRS** وحوّلوها لـ `rules.json`. ده أسرع وأدق من الكتابة من الصفر. (مع التوثيق إنها مستوحاة من CRS.)

### تنظيف SR-BH — الطريقة العملية
```python
# بدل MinHash/LSH المعقد:
import hashlib

def dedup(records):
    seen = set()
    for r in records:
        h = hashlib.sha256(normalize(r['payload']).encode()).hexdigest()
        if h not in seen:
            seen.add(h)
            yield r

# بدل مراجعة يدوية لـ 48K عينة:
# 1. شغّلوا الـ Signatures بتاعتكم على الفئة "السليمة"
# 2. اللي طابق → استبعدوه تلقائياً
# 3. راجعوا عينة عشوائية 200 من الباقي (مش 48K)
```
